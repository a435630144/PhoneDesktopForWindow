## 1. 项目一句话

Python 3.13 + PySide6 写的 Windows 桌面美化工具：在壁纸之上、应用窗口之下的桌面带（Progman 上方）挂一层自绘网格，提供安卓式图标网格 / 文件夹 / 分页 / Dock 栏 / 小组件，双击启动、拖拽整理，托盘常驻。数据全部落在 `%APPDATA%\PhoneDesktop\state.json`（单一真相）。

## 3. 架构总览

```

src/
  desktop_window.py      桌面主窗口(4000行)：拖拽状态机、翻页、框选、剪贴板、文件夹弹窗编排 —— 事实上的"总指挥"
  grid_flow.py           网格几何纯函数层：cell_pos/页换算/让位动画/无界模式。铁律：**本模块不认识 Dock**
  grid_metrics.py        网格几何快照 compute()：cols/rows/ox/oy/cw/ch，由 set_grid 写入全局快照
  grid_sizing.py         cell 尺寸公式（与原生图标尺寸反解）
  iconwidget.py          AppIcon：图标控件(拖影/长按菜单/多选/标签绘制)
  label_style.py         标签文字+预览框样式的**唯一数据源**(NamedTuple)，绘制层不许自己拼颜色
  folder_popup/forms     文件夹弹窗与表单
  dock.py                Dock 栏：inset()是网格扣除**唯一入口**；bar_rect/item_rect 纯函数
  widget_layer.py        小组件层(创建/销毁/翻页跟随/孤儿清扫)
  widget_base.py         FloatingWidget 基类(几何持久化/_flush_pending 钩子)
  widgets/*/             8 个内置组件(clock/notes/monitor/todo/calendar/weather/music/panel)
  widget_plugin.py       第三方 zip 组件：无沙箱(明示决策)，zip-slip 有主防线
  widget_store.py        组件商店(3 镜像，sha256 **硬性要求**——2026-10-25 起)
  widget_shop.py         商店 UI(下载在后台线程 _InstallWorker)
  storage.py             state.json 读写：原子写+fsync、损坏备份、类型清洗(2026-10-25 加固)
  win32_layer.py         桌面带挂载/SetParent/隐藏原生图标(ShowWindow 而非注册表)/自愈
  band_guard.py          Win+D / explorer 重启守护
  desktop_hotkeys.py     WH_KEYBOARD_LL 全局钩子(桌面 Ctrl+C/V)
  liquid_glass.py        液态玻璃折射(边缘带与中部同源采样——2026-10-25 修色差)
  i18n.py + i18n/*.json  词表 zh/en 各 473+ key，回退链 T→ZH→key
tests/                   103 个独立脚本测试(非 pytest)
Component/               组件仓库副本(测试依赖)
```

**数据流铁律**（交接必读，违反就是回归 bug）：
1. `state.json` 是唯一真相；`Storage.save()` 原子写；图标实例只是视图。
2. `dock.storage_inset()` 是网格可用区扣除的**唯一入口**；`grid_flow` 不 import dock。
3. `label_style.label_style()/preview_style()` 是标签/预览框样式的唯一数据源。
4. 设置页只写设置，几何重算交给窗口（`apply_dock_settings` / `refresh_grid`），"窗口是唯一写者"。
5. 图标显隐判断收敛中（zen/翻页/同步多处）——新增 show()/hide() 前先看 `_cull_page_icons`。

## 4. 核心机制速记（防止误改）

- **桌面带挂载**：找 Progman→SHELLDLL_DefView→WorkerW，SetParent 到桌面带；失败退化为悬浮窗（功能不变）。`BandGuard` 轮询 DPI/分辨率/explorer 存活，变化即重挂。
- **网格快照**：`grid_flow.set_grid()` 在窗口几何变化时重算并写全局 `_current_metrics`；一切 `cell_pos/cell_size/rows_per_page` 读快照，**禁止**另算一份（历史双源漂移教训见 T3）。
- **分页**：页是纯视图概念 `page = row // rows_per_page`；翻页=平移全体；`_cull_page_icons` 保证只显示当前页（禁半截）。
- **纯净模式(zen)**：会话级状态，所有图标显隐出口都要乘 `not self._zen`（2026-10-25 B7 修的就是漏乘的四处）。
- **拖拽双区模型**：核心区(图标中心)触发合并，外围触发让位；拖影是 frameless 顶层窗，`_press_pos` 是抓取偏移——**任何路径都不能把它弄丢**（B2 教训）。
- **组件商店信任链**：HTTPS + sha256 硬校验；插件加载=执行任意 Python(无沙箱是明示取舍，见 widget_plugin.py docstring)。
- **桌面快捷键**：NOACTIVATE 窗口收不到键盘 → WH_KEYBOARD_LL 钩子
  （desktop_hotkeys.py）判"指针在桌面 + 前台不盖指针 + 有事可做"才接管；
  Delete/Ctrl+A/Ctrl+Z/C/V 全在这条链上（keyPressEvent 里是死代码）。
- **BandGuard 双通道**：1.5s 轮询兜底 + SetWinEventHook 事件驱动（前台
  切换/z-order 重排立即归位，80ms 限流）。**WinEvent 回调对象必须随实例
  保活**（被 GC = 悬空函数指针，真实事件一到就崩）；closed 弹窗
  `_closing=True` 不进复活路径。
- **弹窗开合与锚点**：幕布 setMask 挖掉锚点瓷砖（按住文件夹直接拖，
  掩膜是窗口本地坐标）；_keep_until_destroyed 保住收起动画的引用。
- **FrameDriver（v14p）**：effects.FrameDriver/drive_property——
  QPropertyAnimation 的帧率受控等价物（tick=1000/渲染频率档），九处
  动画入口已换装；QPropertyAnimation 走 Qt 内部时钟改不了频，新动画
  一律用 FrameDriver。曲线传枚举常量也行（已归一）。
- **大文件夹（v14t/u）**：entry["big"] per-folder；2×2 瓷砖内部 3×3
  直显成员（>9 个第 9 格「…」）；派生 3 格并入 _widget_cells/
  occupied_cells（不可落子）；右键「放大/缩小」、弹窗空白右键设内部
  尺寸布局（_build_size_menu）。右贴边放不下时铺包自动换行。
- **右键原生菜单（v14m）**：shell_verbs.native_menu = pywin32
  IContextMenu 镜像（360 等第三方解压项可达）；静态注册表动词只是
  COM 失败的兜底；zip 另有 CopyHere 自带「全部解压缩」保证可用。

## 6. 遗留问题（分析报告中未修项，按优先级）

1. **性能**（中等收益、低风险）：翻页动画每帧全窗 update（P1）；文件夹瓷砖每帧 SmoothTransformation 缩放可加缓存（P2）；拖拽命中测试全量扫描可缓存+节流（P3）；WM_NCHITTEST 线性扫描可 O(1) 反算（P4）；壁纸注册表 TTL 0.4s<轮询1.2s（P5，一行改）。
2. **持久化**：`set_setting` 每次全量落盘（M2——多数滑条已改 sliderReleased 落盘，剩余项按需跟进）；~~monitor 网络盘采样阻塞（M3）~~已缓解（自适应跳采样，v14w）；~~面板搜索每键全量重扫（M4）~~已缓解（200ms 防抖，v14w）。
3. **i18n**：组件绘制文案硬编码中文不走词表（M5，切英文后组件仍中文）。
3b. **审核报告遗留**（docs/项目审核-2026-10-26.md，P1/P0-3/P2-2/4/5 已修）：
    360 解压项静默无效（P2-1，zip 自带解压兜底）、大文件夹边界（P2-3）、
    BandGuard widget 侧 untrack 核对（P2-6）、巨型类拆分等（P3）。
4. **安全路线图**：插件签名(ed25519)替代现在的"无沙箱+商店sha256"（S1/S3 中期项）；zip 解压改流式限长防炸弹（S4）；`startswith` 副防线改 `is_relative_to`（S5）；更新 URL scheme 校验（S8）。
5. **小项**：BandGuard._items 只进不出（低-1）；图标缓存无 LRU 上限（低-5）；粘贴失败无提示（低-9）。
