# 8.3.1（v14x）· 发布包终于追上 main + 配置备份/迁移

> 8.3.0 的发布页上挂的是 **v14n** 构建，之后 v14o–v14w 六批修复（含两个真崩溃）
> 一直没进任何安装包——下载 8.3.0 的用户其实拿不到。本版把 main 上的全部内容
> 重新出包，并补上用户反复问的「配置怎么备份/迁移」。

## 💾 新功能：配置导出 / 导入

设置 ▸ **高级** ▸ 「备份与迁移」

- **导出配置…**：把布局、图标、文件夹、组件表与全部设置打包成一个可读的
  JSON（`.pdbak`，几百 KB）。不含文件本身——换机后重新扫描桌面即可。
- **导入配置…**：先校验再覆盖，覆盖前把当前 `state.json` 复制成
  `state.json.pre-import-<时间>`，导错、后悔都能找回。
- 坏包不会破坏现有配置：不是本程序的包 / JSON 损坏 / 来自更新版本
  （format 更高）/ 内容缺字段，都会明确拒绝并说明原因，一个字节都不动。
- 也认**裸 state.json**：老用户直接把 `%APPDATA%\PhoneDesktop\state.json`
  拿来导入同样可以。

## 🩹 补齐 8.3.0 发布包缺失的六批修复（v14o–v14w）

- **两个真崩溃**（crash.log 实证）：拖着图标经过设置窗口、取色器点了取消；
- **图标字号**可调（70%~140%）、**恢复默认配置**按钮、**Dock 厚度模型**重做
  （悬停放大吃内边距余量，不再把条带撑胖）；
- **大文件夹**：per-folder 2×2 瓷砖直显成员、右键放大/缩小、弹窗空白右键设内部尺寸；
- **悬停展开/自动关闭时长可调**；
- **全局动画帧率**（FrameDriver）：渲染频率档真正管到图标悬停、组件移动、翻页、Dock；
- 自审批次七处加固 + 饱和度默认档回归。

## ⚡ 性能（v14w 全批）

- 翻页动画不再每帧全窗重绘（省 420ms 期间大半全屏 ARGB 合成）；
- 文件夹成员小图标 / 大瓷砖 ×9 的二次缩放按最终尺寸缓存；
- 拖拽命中不再每次鼠标事件全量扫描；原生模式点击改格子反算 O(1)；
- 壁纸注册表 TTL 0.4s → 1.6s（不再每次轮询真读注册表）；
- 监控组件磁盘采样自适应（网络盘不再卡 UI）、面板搜索 200ms 防抖；
- 图标/像素缓存加上限（512/1024 清半）；`crash.log` / `plugin_error.log`
  超 256KB 轮转。

## 升级提示

- 无需迁移；老 state.json 直接可用。
- 安装包未做代码签名，首次运行 Windows Defender SmartScreen 可能拦截：
  点「更多信息 → 仍要运行」，或把安装目录加进杀软白名单。
- 卸载仍会询问是否删除 `%APPDATA%\PhoneDesktop`（配置目录）；想保留布局
  请选「否」，或先用「导出配置」留一份。
