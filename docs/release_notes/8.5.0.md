## 一、桌面与选择（9 类）

| 现象 | 根因 | 修法 |
|---|---|---|
| 选中「一个应用 + 一个文件夹」合并，**应用本体从文件夹里消失** | 合并时先把 `app` 清空，再拿它构造成员表，取到空表 | 先取本体再清空 |
| 网格第 2 页的图标/小组件**切到无界后跑回第 1 页** | 网格挪页只写 `col/row`，无界页号 `fpage` 停在旧值 | 新增 `Storage.sync_free_pages(ids)`：**只同步这次真被网格移动过的条目**（全局对齐会冲掉用户在无界里摆好的跨页位置，v7 的老 bug 会复活） |
| 粘贴 2 个文件、坏 1 个，**成功那个也不出现** | 部分成功分支漏了刷新桌面 | 只要有成功就 `rescan_desktop()`，托盘仍提示失败数 |
| 2×2 瓷砖拖到时钟旁边，**瓷砖盖住组件** | 让位算法只查主格 | 整块 4 格都查组件占位（排除自己的旧派生格） |
| 「移动到分页」把大文件夹挪过去，**压住目标页图标** | 每个条目只分配 1 格 | 新增 `grid_flow.assign_page_cells`：按真实 footprint 分配，放不下返回 leftovers 并提示 |
| 全窗框选后 Delete，**删掉屏幕上看不见的图标** | 框选不看 `isHidden()` | 只收当前页可见图标 |
| 在第 1 页选中 → 翻到第 2 页 → Delete，**第 1 页的被删** | 选择集不随翻页清理 | 翻页剪掉非本页选择；批量移页后选择跟着走 |
| 「放大」贴最后一列的文件夹，**半个瓷砖在屏外**、旁边图标被盖 | 放大只写 `big=True`，不夹紧不挤人 | `_enlarge_big_folder`：先夹进网格与当前页，再挤走邻居；落点是组件则拒绝并提示 |
| 自动排列时把图标拖到瓷砖上，**瓷砖被"排"到邻居身上** | 密排把 2×2 当 1 格 | 瓷砖从密排队列摘出、整块进占位表；拖的本身是瓷砖时走让位语义 |

## 二、文件夹弹窗（6 类）

| 现象 | 修法 |
|---|---|
| 文件夹已被外部解散（磁盘同步 / 右键解散），弹窗还开着；此时点 **＋ 添加**，那个桌面图标**被彻底删掉**——既不在文件夹里也不在桌面上 | `_add_member_by_id` 以 storage 为准校验宿主仍在；`_on_popup_member_added` 加第二道守卫；外部同步解散时直接关弹窗 |
| 移出/拖出一个成员，**弹窗整体跳到屏幕中央**（离图标几百像素） | `refresh()` 走 `keep_pos=True`，尺寸变化只夹紧不重新居中 |
| 在第 2 页打开文件夹「移出成员」，图标**落在第 1 页**，像被删了 | 优先 `first_free_cell_in_page(当前页)`，没有空位才回退全局 |
| 图标缩放 ≥125% 时，**标题压到右上角 ○ 按钮上**，点标题右端弹出的是颜色面板 | `_title_rect` 按实际按钮组左界反算；按钮组尺寸原本随缩放走，标题让位宽度却是常量 |
| 超长文件夹名在标题里**被硬裁成半截字** | 标题改用 `elidedText`，与成员标签同一套省略规则 |
| 弹窗右键「文件夹大小」的勾选**恒按 3×3** | 改走 `storage.folder_frame(entry)`，读实际生效的默认尺寸 |

## 三、小组件（5 类）

| 现象 | 修法 |
|---|---|
| 删除内置时钟/便签/面板，**重启又回来** | 删除时留墓碑 `settings["widgets_removed"]`，`_migrate` 跳过；旧实现每次 `_load()` 都按固定 id 补齐默认组件，区分不了"老配置缺键"和"用户删掉了" |
| 进「编辑」态改尺寸或直接拖动松手，组件**永久往左上挪一格**并写进 state.json | 编辑态窗口比卡片四周多一圈手柄留白，而"窗口→格位"反算用的是窗口左上角。新增 `_card_origin()`（卡片原点），三处 `pos_cell` 统一改用 |
| 关掉「显示桌面小组件」后从组件库添加，**组件照样出现在桌面上**（重启才消失） | `_spawn` 落位前看总开关；`reload_all` 之后按开关统一 `set_visible` / `sync_page` |
| 网格里把组件拖到第 2 页，**切无界又回第 1 页** | `_save_geom` 调 `sync_free_pages`，与图标同一规则 |
| 关掉总开关再打开 / 退出纯净模式，**其它页的组件一起亮在当前页** | `set_visible` 按页归属显示，并尊重总开关 |

## 四、Dock 与设置（5 类）

| 现象 | 修法 |
|---|---|
| Dock 满 24 项时从桌面拖第 25 个到中间，**末尾那项被静默删除**；拖到末尾则毫无反应 | `add_item` 满员直接返回 False（拖动显示"未接收"），不再靠规范化层截断 |
| 「全部恢复默认」把用户攒的 **Dock 应用列表和天气城市一起清空**，而且永不自动补回 | `reset_settings` 保留内容键（`dock_items` / `dock_seeded` / `weather_city` / `extra_pages` / `page_rules`）与一次性迁移标记 |
| 恢复默认后「显示桌面小组件」回到开，**桌面上的组件却不出现**（导入备份时反向：设置是关，组件全冒出来） | 重置改走 `DesktopWindow.reload_from_storage()`，不再手搓钩子清单；`reload_all` 末尾统一按开关设可见性 |
| 恢复默认后**开机自启还在**（设置里是 False，注册表项仍活着，下次开机照常启动） | 重置时 `autostart.set_enabled(False)`，注册表失败不阻断重置 |
| 把「阴影浓度」「悬停填充」「预览边框」调到 **0**（= 关闭），重开设置面板却显示 75% / 8% / 8px，动一下别的控件就被写回默认——**等于关不掉** | 数值设置统一走 `_num_setting()`：**0 是合法值**，只有 None/空/坏值才回默认 |

## 五、修法里值得记住的三件事

1. **`sync_free_pages(ids)` 必须带 ids。** 页点翻页也会 `save()`，若在其中做"全局按 `row` 对齐 `fpage`"，用户在无界模式里摆好的跨页位置会被无条件重置。
2. **大文件夹的 footprint 有四个入口。** `_free_moves`（整块查组件）→ `_enlarge_big_folder`（夹紧 + 挤人）→ `_arrange_moves`（瓷砖当锚点）→ `assign_page_cells`（按真实 2×2 分配）。少一处就会出现"压格/跨页/出界"。
3. **选择是页级状态。** 框选跳过隐藏项、翻页剪枝、批量移页后跟着走——三者缺一，Delete 就会删到用户看不见的图标。

## 已知遗留（本批没动，写明白）

这 4 项都属于"改一个边缘 case 会牵动整套布局"，单独排批次做：

1. 桌面面板 `setMinimumSize(200,260)` 与 2×2 卡片模型冲突——编辑态缩不下去，重启后跨度自己变大；
2. 分辨率 / 图标尺寸变化后，页底的小组件按新行数落到下一页（row 是全局坐标、页高随几何变）；
3. Dock「四向内边距」的主轴方向仍回退统一 `dock_pad`（左/右位 Dock 的上下内边距不生效）；
4. 文件夹尺寸拉到 6×6 + 200% 缩放时，分页容量按整页算而非弹窗实际高度，最后一行够不到。

## 升级提示

- **无配置格式变更**，直接覆盖安装即可；`state.json` 不需要迁移。
- 恢复默认现在**保留** Dock 条目、天气城市与分页规则——如果你确实想清空它们，请在设置里手动移除。
- 若历史布局里存在"2×2 瓷砖压着图标""组件被挤到下一页"的脏数据，执行一次「重新扫描桌面 / 整理布局」即可归位。
