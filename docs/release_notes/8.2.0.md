# 8.2.0（v14e）· 液态玻璃升级：四个可调光学层 + 僵尸进程自愈

> 研究了 [liquid-glass-react](https://github.com/rdev/liquid-glass-react)（Apple 液态玻璃
> 效果的 Web 参考实现），把它最有辨识度的光学层搬进本项目的折射管线，全部做成
> **设置里可调的选项**；同时修复两桩实机事故（僵尸进程 / 图标未恢复）。

## 🧊 四个可调光学层（设置 ▸ 外观 ▸ 液态玻璃）

| 选项 | 默认 | 效果 |
|---|---|---|
| **玻璃饱和度** | 140% | 玻璃下的壁纸颜色更鲜艳——参考实现的默认值，也是它"像 Apple"的主要来源；100% = 不调 |
| **磨砂程度** | 100% | 中部玻璃的模糊量：0 = 清透玻璃（图案清晰可见），100 = 原版全磨砂 |
| **边缘色散** | 关 | 折射带最外圈出现红蓝错位——红光偏折更强的棱镜光谱，只叠最外一圈 |
| **边缘高光** | 关 | 顶部受光的内描边（上亮下暗），是"光照出来的边"，不是均匀发光边 |

- 拖动滑条**即时生效**，文件夹 / 小组件 / Dock 三个表面统一更新，无需重启；
- 色散与高光**默认关闭**：此前的目检结论是"不要发光描边"，它们只作为可选项存在，
  想要更浓的"玻璃感"再开；
- 玻璃饱和度默认 140%：升级后玻璃下的颜色会比之前**略艳**，不喜欢可在滑条调回 100%；
- 「恢复默认」按钮同时覆盖这四项。

## 🩹 僵尸进程自愈（实机事故 2026-10-25）

桌面带窗口被外部销毁（第三方桌面整理 / 显示桌面切换可能连带清理跨进程窗口）后，
旧版进程不退出也不重建：任务管理器里活着，但没有托盘、没有桌面、右键失灵。
现在守护每轮检查受护句柄的存活性：

- 句柄死了但控件还在 → `destroy()+show()` 重建原生窗口并重新挂载；
- 2 分钟内复活超过 8 次（风暴）→ 恢复被隐藏的原生桌面图标并安全退出；
- 全部死亡且无可复活控件 → 同样恢复图标后退出，不再留僵尸。

## 🔧 退出路径补漏（实机事故 2026-10-25）

标题栏 WM_CLOSE 直退（不经托盘的退出路径）不会恢复被隐藏的原生桌面图标，
冻结包里 `atexit` 也不执行。现在恢复统一挂在 `aboutToQuit`——Qt 一切正常退出
的公共汇合点，恢复逻辑幂等，与托盘路径 / 看门狗多次调用无害。

## 升级提示

- 已有用户的液态玻璃设置自动获得新默认值（饱和度 140 / 磨砂 100 / 色散 0 / 高光 0），
  不需要任何迁移；
- 想要"纯净玻璃"观感：磨砂调到 0、饱和度 100；想要更戏剧化的效果：色散 30~60 + 高光 40~80。
