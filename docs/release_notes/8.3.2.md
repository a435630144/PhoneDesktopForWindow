# 8.3.2（v14y）· 多选拖动不再把块内图标甩到下一页

> 用户反馈（2026-10-27）：框选 2×2 四个图标，抓住**右上角**那个拖到最底下一行松手，
> 块内**下面两个**被自动挤到了下一个分页。

## 根因

多选拖动走的是"整块刚性平移"（`grid_flow.multi_move`）：主条目落指针格，其余成员保持
原相对偏移，然后整块夹进边界。但夹紧只做了**左右**和**上边界 0**，垂直方向**没有页底
夹紧**——bbox 允许延伸到 `+∞`。而"页"是纯视图概念（`page = row // 每页行数`），
所以块多占一行 = 换到下一页：2 行高的块落到底行，下面那行就整排消失到第二页。

这不是渲染问题，是布局真的被写到了下一页，翻回去才看得到。

## 修法

整块垂直夹紧到**落点所在页**，与贴右/贴左同一策略：

- **贴页底** → 整块上移，形状与相对偏移守恒（抓在手里的图标随块一起上移一格）；
- **贴页顶**（第 2 页往上拖）→ 整块下移，不再窜回上一页；
- **块比一页还高**（例如 6 行高的选择）→ 对齐页顶、允许向下溢出——宁可溢出也不丢条目。

顺带修了让位图标的去向：整块下移一格时，每个成员的源格恰好被自己的队友接住，
旧逻辑会"顺延"把下方两个图标甩到本行右侧；现在优先回填**块净空出的格**（同列优先），
看起来就是下面两个图标平滑地滑回块腾出的空格。

## 判据

`tests/test_multi_move.py` 新增 MM7–MM10：页底夹紧、第二页顶部夹紧、超高块、
右下角双轴同时夹紧；随机 200 轮不变量（无叠格 / 数量守恒 / 不越界）照旧。
全量 108 个测试脚本 + smoke 全绿。

## 升级提示

- 无配置迁移；8.3.1 的「导出配置 / 导入配置」原样可用。
- 已经因为这条 bug 被挤到下一页的图标不会自动挪回——手动拖一下即可。
