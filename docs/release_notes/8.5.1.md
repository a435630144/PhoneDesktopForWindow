## 一、设置面板（7 类）

| 现象 | 根因 | 修法 |
|---|---|---|
| 液态玻璃总闸关着时切到 Dock 页，开关显示"关"；随手改一下 Dock 图标大小，那个**从没关过的开关被永久写成 False**——总闸再打开 Dock 也不液态了 | 开关初始化读派生值（总闸 AND 原键），写回却是原键 | 读原键（`dock_flag()`）；总闸关时开关禁用；不透明度置灰改判"此刻是否真的生效" |
| 关掉「自动行列」后点列数 ▲，数字**当场弹回旧值**；60ms 后桌面按新值重排，面板却一直显示旧值 | 写入走 60ms 去抖，紧接着却立刻回读——拿到的是改动前的几何快照 | 回读统一挪到几何落地之后（`_after_grid_rebuilt()`） |
| 选 English → 恢复默认配置：面板重开仍是英文、下拉显示「自动」，重启才一致 | `reset_settings()` 改回了 `language`，但运行态语言只由下拉驱动 | 新增 `_reload_language()`，重置 / 导入备份都过它 |
| 标签描边色改成红 → 点「重置」：粗细回默认，颜色按钮仍写着红 | 重置漏同步描边色样本与按钮 | 补 `_sync_outline_color_btn()` |
| 英文界面下「每页排序规则」第一项是中文「跟随全局」 | `INHERIT` 是空串，拼出 `"page_rules."`（词表里没有） | 新增 `page_rules.label_key()` |
| 关掉「图标悬停」「落点预览框」「文件夹悬停」后，下面滑条照样能拖、照样写盘 | 同页的阴影/描边有统一置灰，这三个父开关没有 | 三个 `_sync_*_controls()` |
| 拖 Dock 不透明度滑条：**每像素**一次临时文件 + `fsync` + `replace`；一步间距调整写 9 次 | `set_setting()` 内部同步 `save()`，"250ms 合并落盘"的定时器只是空转 | `set_setting(..., save=False)` 只改内存（默认行为不变）+ `_save_timer` 合并 + `hideEvent` 兜底 |

> 性能账的量级：一次外观改动 **7 次写盘 → 0 次**；连续拖动 **35 次 → 0 次**，
> 松手/关面板时合并成 1 次。

## 二、桌面占位（8 类）

病根一条：**"这一格能不能放"有太多个各自为政的判定**。

| 现象 | 根因 | 修法 |
|---|---|---|
| 桌面每个**普通**文件夹右侧和下方永远空三格，图标排布到处是洞 | `big_extra_cells()` 只看 `type == "folder"`、不判 `big` | 非大文件夹不产生派生格 |
| 左上角有 2×2 瓷砖时，托盘「添加应用」的新图标**叠在瓷砖右半格上**、点不动 | 页内寻位漏传 storage（不追加派生格），也漏 Dock 禁放格 | 与 `first_free_cell()` 完全同源 |
| 时钟落在瓷砖右/下半边，压上去**再也不挤开**，瓷砖里两个成员永远点不到 | 寻位与挤位都只比主格，而放大逻辑又拒绝"四格里有组件" | `_cell_blocked_by()` 按 4 格整块判，瓷砖整块让位 |
| 在第 2 页把文件拖到某个图标上，被压的图标**跑回第 1 页、还压在瓷砖底下**（像凭空消失） | 挤人时从 `(0,0)` 全局扫 | 优先同页找空格，页满才跨页 |
| 第 2 页以后右键「解散文件夹」，成员**全丢到第 1 页** | 逐个 `add_app()` 无落点 → 全局扫 | 先移除容器，再按文件夹所在页落位 |
| 页满时组件把图标挤到下一页，图标仍算"可见"——**Ctrl+A + Delete 会删掉屏幕外看不见的条目**（开回收站会把真实文件送进去） | 挤位溢出后没人按落点页收编 | 补 `_cull_moved_icons()` |
| 成员拖出的红框画在**屏幕外**，松手却落在别处 | 红框用全局扫描，真实落点用页内扫描 | 两个入口统一 |
| 框选含 2×2 瓷砖的一组拖到最右列：瓷砖右/下半先飞出网格，松手又弹回一格 | 多选 bbox 只记主格 | 对 `big` 条目多记一格 |

## 三、Dock 与文件夹弹窗（7 类）

| 现象 | 根因 | 修法 |
|---|---|---|
| Dock 放 20+ 项（或左右位 12+ 项、125% 缩放）时，**后半段图标直接没了**：看不见、点了没反应、也拖不出去 | 条带长度被夹到屏幕，图标坐标仍按未夹的步长累加 | `_fitted_icon_gap()`：先压间距到 0，再按需等比缩图标（下限 24） |
| `dock_offset_y` 把条带推向屏幕内侧后，**最后一排图标被条带压住**、点击被吃掉 | 网格可用区只按贴边厚度算 | 正偏移计入对应边的预留带 |
| Dock 已满 24 项时拖第 25 个：条带闪一下，用户以为"加过了" | "满员"和"重复"返回同一个 False | `last_reject` 区分 `full` / `dup` |
| 弹窗开着时在资源管理器删掉某个成员：点第 1 个图标**启动第 2 个应用**，右键「移出」把别的成员弹回桌面 | 成员被就地修剪，弹窗控件不重建，而拖拽 payload 用成员**下标** | 外部同步时对存活的文件夹也 `refresh()` |
| 「添加应用」里名字折两行时，**第二行被下一行图标压掉半截** | 格高写死 58，内容需要 67 | 格高按图标 + 两行文字算 |
| 左位 Dock 的 hover 抬升方向朝屏幕外 | `lift` 对 left 取负号 | 方向化 `dx/dy`（实测被夹紧吸收，视觉无差异，修的是语义） |
| 仅小组件模式 ↔ 布局模式下拉双向失同步；设置窗关掉再开显示旧值 | 可用态只在建窗时读一次；隐藏实例被复用 | `_sync_layout_mode_controls()`；只复用可见实例 |

## 四、用户反馈五条（v15f）

- **文件右键菜单**折叠：资源管理器四十多项菜单只常驻常用动词，其余收进「更多系统操作」。
- **图标标签字体**复刻系统桌面：`Segoe UI` 优先 + 雅黑回退 + 字距 100%，阴影晕 0.55 → 0.30。
- **快捷方式自定义图标**：`.lnk` 的 `GetIconLocation` 不再被忽略（VALORANT 显示成 Riot Client 的图）。
- **Ctrl+Alt+A 截图不再被吞**：有 Alt/Shift/Win 按着就整次放行。
- **系统「显示桌面」后程序再也显示不出来**：`_want_visible` 意图位 + 守护按真实可见性拉回 + 挂载期挂起等待。

## 五、仍已知未修（不影响日常使用）

- 分辨率 / 图标尺寸变化后，页底组件按新行数落到下一页（需要一次全局迁移，慎动）。
- 文件夹 6×6 + 200% 缩放时，弹窗高度被夹后成员行不重排、宽度未夹
  （极端组合；已定位到 `_member_box()` / `_member_pitch()`，下一步做 `_fit_scale`）。
- 托盘 tooltip 只在启动时设一次，切语言要重启才变。
