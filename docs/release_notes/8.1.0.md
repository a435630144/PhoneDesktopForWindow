# 8.1.0（v14d）· 2026-10-25 修复批次：数据安全 + 安全加固 + Dock 两侧网格

> 承接 8.0.2。这一版是全量代码体检（《代码分析报告 2026-10-25》）落地的
> 修复批次：14 项交互 BUG、2 项安全加固、state.json 三重防护，外加
> 「Dock 两侧布置网格」等 5 项体验改进。103 个测试文件全绿。

## 🛡️ 数据安全（state.json 三重防护）

- **损坏先备份再回退**：state.json 解析失败或结构异常时，原文件先改名留档
  （`state.json.corrupt-<时间戳>`）再回退默认值——不再出现"回退后第一次保存
  就把原布局永久覆盖"；
- **元素类型清洗**：手改 / 半写入造成的"JSON 合法但元素类型不对"不再启动即崩，
  坏元素视同缺失，其余照常加载；
- **写入加固**：保存时 fsync 落盘；保存失败会写 `storage_error.log` 并清掉
  半成品临时文件（掉电 / 强杀优先留旧文件，而不是 0 字节新文件）。

## 🔒 安全加固

- 组件商店下载的组件包 **sha256 校验改为硬性**：清单里没有哈希或哈希不符一律
  拒装（此前清单缺哈希时静默放行）；
- 全局键盘钩子（桌面 Ctrl+C / Ctrl+V）改为**先判断桌面是否有焦点，再决定拦不
  拦**，不再吞掉其它应用的快捷键。

## 🐛 修复的交互 BUG（摘选）

- 纯净模式退出后 Dock 栏不再永久消失；翻页 / 桌面同步也不再"穿透"纯净模式；
- 手机模式（按住滑动变拖动）拖影不再冻结、落点不再错乱；
- 多个图标一起拖进文件夹不再静默失效；Ctrl+A 只全选**当前页**（不再跨页全选，
  消除误删隐患）；
- 组件商店下载挪到后台线程，慢网络不再冻住设置窗口几十秒；
- 新图标入场不再挤到小组件占的格子上；
- 便签 / 待办清单退出时最后一段输入不再丢失（托盘退出前统一落盘）。

## ✨ 新功能与视觉

- **Dock 两侧布置网格**（设置 ▸ Dock 栏 ▸ 基础，默认关）：开启后水平 Dock
  不再整边扣掉网格，只有 Dock 实际压住的格子禁放（拖过去无预览、松手回弹），
  两侧空区照常摆图标；垂直 Dock 不适用；
- **图标文字阴影还原 Windows 原生**：四向 1px 暗晕 + (+1,+1) 主阴影两层，
  还原原生"四向都有、下方更深"的观感（浓度仍由原设置控制）；
- **hover 放大不再文字抽动**：动画帧的标签整层渲染成图缓存后平滑缩放，
  静止时仍直接画字保持清晰；
- **液态玻璃色差修复**：磨砂区的暗纱烘焙进中部底图，边缘折射带从同一张底图
  采样，不再出现"磨砂区与折射区两套颜色"；
- **落点指示框可整体关闭**（设置 ▸ 图标 ▸ 移动预览框首行，默认开）。

## 升级提示

- `dock_side_grid` / `cell_preview_enabled` 均为新增设置，默认值保持原有行为
  （关 / 开），升级后无需任何操作；
- 若曾遇到启动即崩或布局丢失，`%APPDATA%\PhoneDesktop\` 下会留有
  `state.json.corrupt-*` 备份可供抢救。
