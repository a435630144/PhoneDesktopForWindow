# 8.0.2（v14c）· 液态玻璃：实时折射 + 成为一种配色

> 承接 8.0.0 的「液态玻璃」。这一版把它从"能看"改到"对"：底图**实时**跟着
> 组件位置走，并且液态玻璃正式成为**一种配色**（和颜色同级、互斥）。

## 🧊 液态玻璃现在是实时的

上一版是"表面打开时抓一次屏"，之后图案就定住了——组件被拖走，玻璃里还是
创建位置那一块壁纸（用户实测：左上角的天空色一直跟着组件跑）。现在改成：

- 启动后把**整块虚拟桌面**的壁纸按 Windows 的填充方式（填满 / 适应 / 拉伸 /
  居中 / 平铺 / 跨屏）合成一张图，任何表面按自己的**全局矩形**从里面裁一块；
- 组件拖动 / 缩放：矩形一变就重算（压到 30fps），玻璃里的图案跟着走；
- 换壁纸 / 改分辨率：每秒比对一次版本号，自动重建。

成本：300×240 的组件一次重算 **2.5ms**，Dock 1.4ms（只算一次后缓存），
拖动时不会卡。

## 🧊 折射方向修正：向"外"采

边缘看到的是玻璃**外面**的世界被压进来。第一版是向"内"采样，映射不单调，
会在边缘折出一圈被抹平的色块（已目检确认并修正）。现在底图会带一圈外扩，
圆角处也自然。

## 🧊 没有高光、没有描边

- 删除第一版的贴边亮带 / 四色色散 / 噪声 / 扫光（那是"发光描边"，不是玻璃）；
- 轮廓改成**自适应细线**：暗底用白线、亮底用黑线，只有 26/255；
- 很亮的壁纸上会加一层极淡的暗纱（最多 40/255），保证白字读得出来；
- 纯色壁纸下逐像素不变（判据：折射不改变颜色，只改变位置）。

## 🎨 液态玻璃 = 一种配色（与颜色同级、互斥）

| 位置 | 怎么选 | 选了液态之后 |
|---|---|---|
| 文件夹 | 文件夹 ▸ ○ 色板，**第一颗是"透明棋盘格"圆片** | 文件夹图标变成玻璃瓷砖，弹窗背景透明折射，不再叠文件夹色 |
| 小组件 | 组件设置 ▸ 外观 ▸ **液态玻璃**开关 | 背景颜色 / 背景不透明度**置灰**（值保留，关掉就回来） |
| Dock 栏 | 设置 ▸ Dock 栏 ▸ 外观 ▸ **液态玻璃**开关 | 背景不透明度置灰 |

- 组件开关的默认值按"有没有设过背景色"推导：设过颜色就走颜色（尊重老配置），
  没设过就走液态；一旦手动拨动，就按手动值。
- 设置 ▸ 外观只剩**总开关 + 折射强度 + 折射带宽**——三个表面开关已移到各自的
  配色里（"这个元素要不要玻璃"本来就该在它自己的设置里）。

## 其它

- 禁用态控件补了样式（滑条手柄退灰、按钮文字变淡），"不可调"看得出来；
- 液态条带的边框不再用旧的不透明度推算（那会变成一圈发白描边），收到 16%。

## 升级提示

- 文件夹默认仍是原来的颜色（不会因为升级突然全变透明）——想要液态玻璃，
  在色板点第一颗圆片；
- 没设过背景色的组件会自动变成液态玻璃；
- 动态壁纸（Wallpaper Engine 等）读不到静态文件时，会退回"打开时抓一次"
  的旧行为，建议这类桌面关闭液态玻璃。
