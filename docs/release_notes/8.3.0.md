# 8.3.0（v14j）· 反馈批次：稳定性 + 文件夹交互 + 液态玻璃优化 + 设置新页

> 2026-10-25 一批实测反馈的集中修复与增强，共 16 项。全部逐条带回归测试落地。

## 🩹 稳定性

- **多次悬停展开文件夹后"退出接管/先回原生桌面又闪回"**：根因是文件夹弹窗与幕布在打开时被守护登记、关闭后从不摘除——守护把"正在收起动画的窗口"当成"被外部销毁"去拉活，多次开合喂爆复活风暴（120 秒 8 次）后程序恢复原生图标并退出。现在关闭前摘登记、`_closing` 窗口不进复活路径、收起动画期间的引用不再被提前回收。

## 📁 文件夹

- 悬停展开的弹窗移走后 **450ms 关闭**（原 750ms）；
- hover 展开后点开**配色 / 添加应用面板**，鼠标在面板上不再被当"离开弹窗"误关；
- 在资源管理器里把文件移走/删除后，文件夹**死成员自动修剪，只剩一个自动解散**（最后一名回桌面）；
- 弹窗内成员右键新增**「在文件夹中显示」**；
- 弹窗内**横滑翻页**阈值 28→22px，更跟手。

## 🧊 液态玻璃

- **折叠态的液态玻璃文件夹瓷砖真折射**：此前只有透明+白边，与弹窗两种材质语言；现在与弹窗同一折射管线（同一总闸与参数，壁纸快照不可用时退回原观感）；
- 组件拖动时的**重算抽动**：玻璃饱和度上移到快照层整图烘焙一次，拖动重算只剩 C++ 裁剪 + 条带位移。

## 🖼 图标

- hover 动画时**文字发糊**修复：标签贴图按当前帧缩放烘焙（原按 1.0 倍烘焙再放大重采样），阴影与文字同层同缩放；
- **悬停高亮与动画自定义**：设置 ▸ 图标与标签 ▸ 悬停高亮——颜色（含透明度）/填充浓度/放大幅度/动画时长，均可调、可全关。

## 🧩 小组件

- **编辑尺寸时内容不再消失**：此前自绘组件（时钟/天气/音乐/日历/监控等）在编辑态只剩空玻璃；
- 组件库**免重启识别**新插件：页签行新增「刷新」（重扫本地组件目录）；商店安装完成后本地卡片自动重建；
- 组件库 UI 收紧：删去与页标题重复的页内标题、上方空白收紧；单列时卡片限宽 420px 居中（原拉伸到 700+px）。

## ⚙️ 设置

- **渲染频率升级为全局动画帧率**：液态玻璃重算与自驱动动画（如监控组件数值弹簧）共用一档；QPropertyAnimation 走 Qt 内部时钟不受档位影响；
- 新增独立**「关于」页**：软件名 / 版本构建标识 / 检测更新 / 关于作者。

## 🖱 桌面右键

- 文件右键追加**原生菜单动词**（注册表 shell verbs，如文本文件的编辑/打印）；
- 已知边界：若解压菜单由 shellex COM 插件提供（如部分第三方压缩软件），静态注册表动词拿不到，该类项不可复刻。

## 升级提示

- 无配置迁移；老 state.json 里的 `opacity` 等残留键无人读取，无害。
